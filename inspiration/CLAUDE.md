# Inspiration 灵感库

## 定位

独立的灵感捕捉区，用于记录瞬间的想法、创意片段、随想。

## 特性

- **按天记录**：每天一个文件，多条灵感追加到同一文件
- **仅供引用**：不归档、不整理，保持原样
- **轻量级**：快速记录，无严格格式要求
- **独立存在**：不属于 PKM 工作流，不需要 GTD 处理

## 目录结构

```
inspiration/
├── CLAUDE.md       # 本文件
├── 2025-12-25.md   # 按天记录
├── 2025-12-26.md
└── ...
```

## 文件格式

每日文件：`YYYY-MM-DD.md`

```markdown
# YYYY-MM-DD 灵感记录

---

## 灵感标题（简短描述）

**时间**: HH:mm

灵感内容...

---

## 另一条灵感

**时间**: HH:mm

内容...

---
```

## 用途

- 突发灵感
- 产品想法
- 创意片段
- 写作素材
- 任何值得记录的瞬间想法

## 与其他目录的关系

- `output/` 写作时可引用这里的内容
- `life-os/Inbox/` 是 GTD 待处理区，这里是纯记录区
- `news/` 是资讯收集，这里是个人想法
- 不需要定期清理或归档
