# Your Mind

用 Claude Code 驱动的个人数字大脑框架。

**[English](README_EN.md)**

## 为什么会有这个项目

最近我在高频率地用 AI 学习技术、获取资讯，更重要的是用 AI 进行并行开发。在这个过程中，我逐渐变得越来越茫然。

为什么？因为大脑不够用了。

每天接收的信息太多了——技术文章、产品灵感、学习笔记、项目想法——它们像潮水一样涌来，然后又像潮水一样退去，什么都没留下。

所以我决定花点时间，给自己整理一个框架。一个能帮我梳理思绪、沉淀想法的地方。学会思考的方式，就是常常思考，对吧？

于是我想：我最好有一个自己的数字大脑，让 AI 帮我整理、思考、沉淀。

然后就有了这个项目。

## 它是怎么工作的

一开始我写了一个私有仓库叫 `my-mind`，然后就玩得不亦乐乎：

**用 `/collect` 快速收集资讯**——看到一篇好文章？丢给它。AI 会帮我打好标签，放到对应的文档里。我只管收集，不用做整理工作。

**用 `/capture` 捕获碎片思绪**——突然冒出一个想法？说一句话就行。AI 帮我快速记录、分类。

**用交互式的方式写人生规划、日报、周报**——不再需要自问自答。Claude Code 会像教练一样引导我完成这些规范式文档的编写。一切都变得很容易。

## 两个让我决定开源的时刻

**第一个时刻**：某次写日报时，我说「我想写一个好玩的产品，把这个作为今天的目标」。结果 AI 自动帮我捕获到了我曾经在灵感库里记录的一个 idea，问我：「是否要把这个作为目标项目？」然后通过交互式的方式帮我分析这个灵感的可行性。

我震惊了。这就是我想要的。

**第二个时刻**：我突然发现这个大脑的结构是可以扩展的。比如你是产品经理，你大可以基于这个结构，让 Claude Code 帮你编写一个关于产品管理的目录、skills、agents、还有指令。它能很好地理解整个项目的框架，让你的数字大脑自然生长。

你将会拥有一个属于你自己的、独一无二的、且会越来越强大的大脑。

可能唯一的问题就是——token 真的太贵了。但是是值得的，不是嘛？😆

## 快速开始

### 前置要求

- [Claude Code](https://claude.ai/code) - AI 编程助手
- [Obsidian](https://obsidian.md/)（可选）- 我用它来管理笔记，非常好用，但不是必须的

### 安装步骤

1. 克隆或 Fork 本仓库
2. 用 Claude Code 打开项目目录
3. 开始和 AI 对话，探索你的数字大脑吧

## 核心功能

### 命令 (Commands)

命令是你与数字大脑交互的快捷方式，输入斜杠即可触发。

| 命令 | 用途 |
|------|------|
| `/daily` | 创建今日每日笔记，Claude 会交互式引导你规划一天 |
| `/weekly` | 运行周回顾流程，回顾过去一周并规划下周 |
| `/capture` | 快速捕捉灵感，一句话记录闪过的想法 |
| `/collect` | 收集资讯，丢个链接进去，AI 自动打标签归档 |
| `/card` | 创建技术卡片，记录问题解决方案或知识点 |
| `/commit` | 提交变更到 Git |
| `/onboard` | 首次使用时加载完整上下文 |
| `/catchup` | 同步最新状态，让 AI 了解你的近况 |

### 技能 (Skills)

技能是 Claude 的专业能力模块，让它在特定领域表现更好。

| 技能 | 用途 |
|------|------|
| `life-os-file-ops` | 处理 Obsidian 文件的读写规范，管理 frontmatter 和 wiki-links |
| `daily-workflow` | 晨间/午间/晚间工作流，结构化你的一天 |
| `goal-tracking` | 目标进度追踪，计算完成百分比，发现停滞目标 |
| `blog-assistant` | 根据主题或灵感库内容生成文章提纲 |
| `tech-reviewer` | 审核技术卡片，验证准确性，查找资料核实 |
| `skill-creator` | 帮你创建新的 skill，扩展数字大脑能力 |

### 代理 (Agents)

代理是可以自主完成复杂任务的 AI 助手。

| 代理 | 用途 |
|------|------|
| `goal-aligner` | 分析你的日常活动与长期目标的对齐情况，发现偏离 |
| `weekly-reviewer` | 引导周回顾流程，像教练一样问你问题 |
| `note-organizer` | 整理笔记、修复断链、合并重复、建议连接 |
| `inbox-processor` | 用 GTD 原则处理收件箱，分类、澄清、组织 |

## 自定义扩展

这个框架的魅力在于它可以生长。你可以让 Claude Code 帮你扩展任何你需要的能力或者模块，而这些内容，Claude Code会帮你关联起来。

### 添加新命令

在 `.claude/commands/` 目录下创建 `command-name.md` 文件。

### 添加新技能

在 `.claude/skills/` 目录下创建技能目录，包含 `SKILL.md` 文件。

### 添加新代理

在 `.claude/agents/` 目录下创建 `agent-name.md` 文件。

**小提示**：你可以直接告诉 Claude「帮我创建一个用于 XXX 的技能」，它会帮你完成。

### 多语言支持

这个项目目前是中文的，但如果你更习惯其他语言，直接让 AI 帮你把整个项目翻译成你习惯的语言就好了，效果是一样的。

## 设计理念

1. **输入 → 思考 → 输出**：完整的知识流转闭环
2. **AI 原生**：充分利用 Claude Code 的能力，而不是把 AI 当搜索引擎用
3. **结构化但灵活**：提供框架但不限制自由，让大脑自然生长
4. **可追溯**：所有决策和进展都有记录，未来的你会感谢现在的你
