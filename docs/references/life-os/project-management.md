# 项目管理规范

这些约定适用于项目文件夹与相关文档。

## 项目结构

每个项目都使用独立文件夹：
```
Projects/
└── Project-Name/
    ├── CLAUDE.md           # 必需：给 AI 的项目上下文
    ├── README.md           # 可选：复杂项目可补充总览
    ├── notes/              # 可选：项目过程笔记
    └── resources/          # 可选：参考资料
```

## 项目 CLAUDE.md

每个项目必须包含一个 `CLAUDE.md`，内容建议包含：

```markdown
# 项目：[名称]

## 概述
[用 1-2 句话说明这个项目是什么]

## 状态
- **阶段：** Planning | Active | On Hold | Complete
- **进度：** X%
- **开始：** YYYY-MM-DD
- **目标：** YYYY-MM-DD

## 目标
[成功是什么样子（验收标准）]

## 当前聚焦
[我现在正在推进的内容]

## 关键决策
[重要决策与理由]

## 下一步行动
- [ ] 立刻要做的下一步
- [ ] 随后一步

## 阻塞
[任何阻碍进展的因素]

## 资源
- [[相关笔记]]
- [外部链接](url)

## 给 Claude 的备注
[Claude 协助该项目时需要知道的上下文]
```

## 项目状态值

使用一致的状态标签（建议保留英文标签以便统一检索）：
- `Planning` - 规划中：定义范围与方案
- `Active` - 进行中：正在推进
- `On Hold` - 暂停：临时搁置（注明原因）
- `Blocked` - 受阻：等待外部依赖
- `Review` - 评审：工作完成，待复查
- `Complete` - 完成：已结束，可归档

## 进度追踪

### 百分比参考
- 0-10%：规划与准备
- 10-30%：初始推进
- 30-70%：核心工作
- 70-90%：完善与打磨
- 90-100%：最终检查与收尾

### 更新频率
- 至少每周更新一次进度
- 状态变化时立刻更新
- 出现阻塞时立即记录

## 项目链接规范

### 链接到目标
把项目链接到对应的上级目标：
```markdown
**支持：** [[1. Yearly Goals#目标名称]]
```

### 链接到每日笔记
在每日笔记里引用项目工作记录：
```markdown
## 工作日志
- 推进了 [[项目名称]] - 完成了 X
```

### 项目之间互链
关联项目之间互相链接：
```markdown
**相关：** [[其他项目]]
```

## 项目生命周期

### 启动项目
1. 在 `Projects/` 下创建项目文件夹
2. 用模板创建 `CLAUDE.md`
3. 链接到相关目标
4. 定义第一步行动
5. 设置目标完成日期

### 推进中
1. 在 `CLAUDE.md` 更新进度
2. 在每日笔记记录工作日志
3. 记录关键决策与理由
4. 及时记录阻塞
5. 必要时调整时间线

### 完成项目
1. 更新状态为 Complete
2. 补充完成日期与总结
3. 记录复盘与经验
4. 移动到 `Archives/Projects/`
5. 更新目标进度

## 最佳实践

1. 范围务必现实
2. 同一时间只保持一个主焦点
3. 大项目拆成阶段
4. 每周回顾所有活跃项目
5. 完成后及时归档
6. 决策当下就记录
7. 充分使用链接建立上下文
