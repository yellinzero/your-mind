# 生产力工作流规则

本规范适用于 `life-os/Goals/` 和 `life-os/Daily Notes/` 目录。

## 目标级联原则

目标从长期愿景流向日常行动：

```
5 年愿景（人生方向）
    → 年度目标（年度成果）
        → 月度目标（当前重点）
            → 周回顾（本周计划）
                → 每日任务（今日行动）
```

## 目标结构

目标按 5 年周期管理：

```
Goals/
├── 2026-2030/              # 当前周期
│   ├── 0. Five Year Plan.md
│   ├── 1. Yearly Goals.md
│   ├── 2. Monthly Goals.md
│   └── 3. Weekly Review.md
└── (未来周期...)
```

## 目标设定标准

### SMART 原则

每个目标应该是：
- **S**pecific - 明确具体
- **M**easurable - 可衡量
- **A**chievable - 可实现
- **R**elevant - 与上级目标相关
- **T**ime-bound - 有截止时间

### 目标数量限制

- 同时最多 3 个高优先级目标
- 每个目标有明确的成功标准
- 14+ 天无行动的目标需要回顾

## 每日计划规则

### 晨间 (5 分钟)

1. 创建或打开每日笔记
2. 确定当日的 ONE Big Thing
3. 回顾昨日未完成任务
4. 设置合理的时间块

### ONE Thing 原则

> "今天我能做的哪件事，做完之后其他事都会变得更简单或不再必要？"

在 Focus 部分回答这个问题。

### 任务优先级

1. **必须完成** - 不可协商，有截止日期
2. **应该完成** - 重要但时间灵活
3. **可以完成** - 如果有时间
4. **不做** - 明确放弃（承认取舍）

## 周回顾规则

### 时间：周日或周一
### 时长：至少 30 分钟

### 必要元素

1. **收集** - 汇总所有待处理事项
2. **处理** - 对每项做出决定
3. **回顾** - 检查目标进度
4. **计划** - 设定下周优先事项

### 检查清单

- [ ] 所有收件箱已清空
- [ ] 本周所有每日笔记已回顾
- [ ] 目标进度已计算
- [ ] 下周 ONE Big Thing 已确定
- [ ] 日历已检查待办事项

## 进度追踪

### 复选框格式

```markdown
- [ ] 未开始
- [/] 进行中（可选）
- [x] 已完成
```

### 百分比更新

有进展时更新百分比：
```markdown
- [ ] 学习西班牙语 (25% → 30%)
```

### 里程碑日期

记录重要进展：
```markdown
- [x] 完成课程模块1 ✓ 2025-01-15
```

## 时间管理

### 时间块

根据精力安排：
- 🌅 上午：高专注工作 (9-12)
- ☀️ 下午：会议、行政 (12-5)
- 🌙 晚间：轻量任务、学习 (5+)

### 精力追踪

每日记录精力水平 (1-10)：
```markdown
**精力:** 7/10 - 上午状态好，下午有点困
```

## 归档规则

以下情况移至 Archives：
- 项目已完成
- 目标已达成或放弃
- 每日笔记超过 30 天（可选）

归档格式：
```
Archives/
├── Projects/
│   └── Completed-Project-2024/
├── Goals/
│   └── 2020-2024/           # 按周期归档
└── Daily Notes/
    └── 2024-01/
```
