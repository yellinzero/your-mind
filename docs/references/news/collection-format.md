# 资讯收集格式规范

## 概述

本规范定义 `news/` 目录下资讯收集的格式标准，支持多种来源类型和标签管理。

## 资讯来源类型

| 类型 | 识别关键词 | 说明 |
|------|------------|------|
| 网络文章 | 有 URL | 在线内容 |
| 书籍摘录 | 书、阅读、读到 | 书中内容 |
| 播客/视频 | 播客、视频、听、看 | 音视频内容 |
| 对话记录 | 聊天、对话、朋友说、讨论 | 交流获得的洞见 |
| 个人观察 | 其他 | 日常发现 |

## 文件组织

### 周文件命名

| 元素 | 格式 | 示例 |
|------|------|------|
| 文件名 | `YYYYMMDD-YYYYMMDD.md` | `20251223-20251229.md` |
| 周期 | 周一至周日 | 7天一个文件 |

### 周文件头部

```markdown
# 资讯收集 YYYYMMDD-YYYYMMDD

本周收集的有价值资讯。

---
```

### 标签索引文件

路径：`news/tags.md`

```markdown
# 标签索引

按标签汇总所有资讯，便于检索和管理。

## #AI
- [[20251223-20251229#文章标题1]]
- [[20251216-20251222#文章标题2]]

## #投资
- [[20251223-20251229#观点标题]]
```

## 单条资讯结构

### 有链接（网络文章）

```markdown
## [标题](URL)

**标签**：#标签1 #标签2 #标签3
**来源**：网络文章
**收录时间**：YYYY-MM-DD HH:mm

### 内容摘要

> 要点1
> 要点2
> 要点3

### 个人感想

用户的思考与评论

---
```

### 无链接（其他来源）

```markdown
## 标题

**标签**：#标签1 #标签2
**来源**：书籍摘录 / 播客/视频 / 对话记录 / 个人观察
**收录时间**：YYYY-MM-DD HH:mm

### 内容

资讯的具体内容描述

### 个人感想

用户的思考与评论

---
```

## 标签系统

### 格式要求

- 使用 `#标签名` 格式
- 多个标签用空格分隔
- 建议 2-4 个标签
- 优先使用已有标签，保持一致性

### 标签分类参考

| 领域 | 推荐标签 |
|------|----------|
| 技术 | `#AI` `#编程` `#产品` `#工具` `#开源` `#架构` |
| 商业 | `#金融` `#创业` `#投资` `#商业模式` `#市场` `#管理` |
| 成长 | `#思维` `#效率` `#习惯` `#认知` `#学习` `#职业` |
| 生活 | `#健康` `#阅读` `#旅行` `#生活方式` `#人际` |

### 智能打标签规则

1. 分析资讯内容的主题和关键词
2. 匹配已有标签库中的相关标签
3. 如无匹配，根据内容创建新标签
4. 用户指定的标签优先级最高
5. 建议标签数量：2-4 个

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 标题 | ✓ | 简洁描述资讯主题 |
| 标签 | ✓ | 2-4个分类标签 |
| 来源 | ✓ | 资讯来源类型 |
| 收录时间 | ✓ | 记录时间 |
| 内容/摘要 | ✓ | 资讯核心内容 |
| 个人感想 | ✓ | 用户的思考 |

## 内容要求

### 摘要（有链接时）

- 提取 3-5 个关键要点
- 使用引用块格式
- 忠实原文，不添加个人判断

### 内容（无链接时）

- 完整记录用户提供的信息
- 保持原意，可适当整理格式

### 个人感想

- 原样保留用户的表达
- 允许简短（一句话也可）
- 鼓励记录当下的思考

## 维护指南

### 标签索引更新

每次添加新资讯后，同步更新 `tags.md`：
1. 检查资讯的所有标签
2. 在对应标签下添加链接
3. 如是新标签，创建新分类

### 周文件切换

```
周一 00:00 → 自动创建新周文件
当前资讯 → 写入当周文件
```
