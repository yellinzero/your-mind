# 资讯模块 (news/)

## 定位

收集各类有价值的资讯内容，结合个人感想进行记录、打标签与归档。

## 资讯来源类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 网络文章 | 带 URL 的在线内容 | 博客、新闻、论坛帖子 |
| 书籍摘录 | 书中的精彩段落 | 《原则》第三章要点 |
| 播客/视频 | 音视频内容要点 | 播客节目、YouTube |
| 对话记录 | 与人交流获得的洞见 | 朋友分享、会议讨论 |
| 个人观察 | 日常生活中的发现 | 市场趋势、产品体验 |

## 目录结构

```
news/
├── CLAUDE.md             # 本文件
├── tags.md               # 标签索引（自动维护）
└── YYYYMMDD-YYYYMMDD.md  # 按周归档的资讯文件
```

## 标签系统

### 标签格式

- 使用 `#标签名` 格式
- 支持多个标签，空格分隔
- 标签建议用中文，简洁明了

### 常用标签参考

| 领域 | 标签示例 |
|------|----------|
| 技术 | `#AI` `#编程` `#产品` `#工具` |
| 商业 | `#金融` `#创业` `#投资` `#商业模式` |
| 个人成长 | `#思维` `#效率` `#习惯` `#认知` |
| 生活 | `#健康` `#阅读` `#旅行` `#生活方式` |

### 智能打标签

收集资讯时，Claude 会根据内容自动建议标签，你可以：
- 接受建议的标签
- 自己指定标签
- 两者结合

## 单条资讯格式

### 有链接的资讯

```markdown
## [资讯标题](URL)

**标签**：#AI #产品
**来源**：网络文章
**收录时间**：YYYY-MM-DD HH:mm

### 内容摘要

> 关键要点...

### 个人感想

用户的思考与评论

---
```

### 无链接的资讯

```markdown
## 资讯标题

**标签**：#投资 #认知
**来源**：书籍摘录 / 播客 / 对话 / 观察
**收录时间**：YYYY-MM-DD HH:mm

### 内容

资讯的具体内容...

### 个人感想

用户的思考与评论

---
```

## 使用方式

使用 `/collect` 命令收集资讯：

**输入格式**（灵活组合）：
- 网址（可选）
- 内容描述（必需，如果无网址）
- 个人感想（必需）
- 标签（可选，不提供则智能生成）

**示例**：
```
/collect
https://example.com/article
这篇文章讲的观点很有启发，特别是关于 AI 应用落地的部分
#AI #产品
```

```
/collect
今天和朋友聊天，他提到一个观点：投资最重要的是认知边界
对我很有触动，确实投资本质是认知的变现
#投资 #认知
```
