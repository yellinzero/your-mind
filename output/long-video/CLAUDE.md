# 长视频

## 定位

长视频（B站/YouTube 等）脚本和思路创作区。

## 目录结构

```
long-video/
├── CLAUDE.md
├── published.md      # 发布记录
└── 视频标题/
    ├── 视频标题.md     # 脚本/思路
    ├── outline.md      # 大纲（可选）
    └── (参考资料)
```

## 内容格式

### 脚本结构

```markdown
# 视频标题

## 基本信息
- 目标时长：
- 目标平台：B站 / YouTube / 其他
- 主题：

## 大纲
1. 开场
2. 主体内容
3. 结尾

## 脚本正文

### 开场（0:00 - x:xx）
...

### 主体（x:xx - x:xx）
...

### 结尾（x:xx - x:xx）
...

## 备注
- 需要的素材
- 特效/转场
- 其他注意事项
```

## 工作流

1. 记录视频思路和大纲
2. 撰写详细脚本
3. 录制/剪辑
4. 发布后记录到 `published.md`
5. 定期清理已发布内容
