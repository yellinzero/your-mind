# 通稿区

## 定位

跨平台通用内容，写好后可根据需要转换格式分发到各平台。

## 目录结构

```
universal/
├── CLAUDE.md
├── published.md      # 发布记录
└── 文章标题/
    ├── 文章标题.md
    └── (资源文件)
```

## 工作流

1. 创建文章目录和主文件
2. 完成写作
3. 根据目标平台格式调整并复制
4. 发布后在 `published.md` 记录
5. 定期清理已发布的原文

## 格式要求

- 使用 Markdown 格式
- 图片放在文章同级目录
- 保持平台无关性，避免特定平台的格式
