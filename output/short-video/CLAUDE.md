# 短视频

## 定位

短视频（抖音/Reels/Shorts 等）脚本和思路创作区。

## 目录结构

```
short-video/
├── CLAUDE.md
├── published.md      # 发布记录
└── 视频标题/
    ├── 视频标题.md     # 脚本/思路
    └── (参考资料)
```

## 内容格式

### 脚本结构

```markdown
# 视频标题

## 基本信息
- 目标时长：15s / 30s / 60s
- 目标平台：抖音 / Reels / Shorts
- 主题：

## 脚本

### 开头（抓注意力）
...

### 主体内容
...

### 结尾（行动号召）
...

## 备注
- 配乐
- 字幕样式
- 特效
```

## 工作流

1. 记录短视频创意
2. 撰写简洁脚本
3. 录制/剪辑
4. 发布后记录到 `published.md`
5. 定期清理已发布内容
