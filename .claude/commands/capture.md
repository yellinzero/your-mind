# 灵感捕捉

快速记录灵感到当天的 `inspiration/YYYY-MM-DD.md` 文件。

## 使用方式

```
/capture 灵感内容
/capture "多行内容可以用引号包裹"
/capture  # 不带参数则交互式输入
```

## 执行步骤

1. 获取当前日期和时间
2. 确定当天文件：`inspiration/YYYY-MM-DD.md`
3. 如果文件不存在，创建并添加头部
4. 将新灵感追加到文件末尾

## 文件格式

当天文件结构：

```markdown
# YYYY-MM-DD 灵感记录

---

## 灵感标题

**时间**: HH:mm（24小时制，如 14:30）

灵感内容...

---
```

## 示例

**输入**：
```
/capture 也许可以用 AI 来自动整理我的笔记，按主题聚类
```

**追加到** `inspiration/2025-12-26.md`：
```markdown
---

## AI 笔记整理

**时间**: 14:30（24小时制）

也许可以用 AI 来自动整理我的笔记，按主题聚类

---
```

## 标题生成规则

根据内容自动生成简短标题（3-8 字），如果内容包含 URL，可提取网站/产品名。

## 注意

- 灵感记录不需要完美，快速记录最重要
- 同一天的多条灵感都追加到同一个文件
- 之后可以在 output/ 写作时引用
- 不需要归档或整理
